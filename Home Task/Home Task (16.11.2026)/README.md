# Мини-заметки (Mini Notes)

Данный проект представляет собой учебное веб-приложение, разработанное для практики создания современных одностраничных приложений (SPA). Основная цель работы заключалась в том, чтобы собрать полноценный рабочий интерфейс с навигацией, интеграцией с локальным API, обработкой форм и подготовкой к продакшен-сборке.

## На чем писалось

Приложение разработано с использованием фреймворка **Angular** (версии 17 и выше). В проекте применяется современный подход **Standalone Components**, что позволяет обходиться без громоздких модулей и делает структуру приложения более легкой. Для управления маршрутизацией используется встроенный **Angular Router**. Работа с формами построена на **Reactive Forms**, что обеспечивает строгую типизацию и удобную валидацию вводимых данных. Взаимодействие с сервером осуществляется через **HttpClient** и библиотеку **RxJS**, которая позволяет удобно обрабатывать асинхронные запросы и подписываться на изменения данных. Шаблоны компонентов написаны с использованием нового синтаксиса Angular (блоки `@if`, `@for`, `@empty`). Для эмуляции серверной части используется пакет **json-server**, который работает с локальным файлом базы данных.

## Для чего нужно было это приложение

Этот проект создавался как практическое задание для закрепления навыков разработки на Angular. Основная задача — реализовать полный цикл работы с данными (CRUD — создание, чтение, удаление). Приложение позволяет пользователю просматривать список заметок, добавлять новые записи через форму с валидацией полей и удалять ненужные заметки. Кроме того, важной частью работы было научиться обрабатывать состояния загрузки (показывать индикатор, пока данные не получены) и корректно обрабатывать ошибки сети, например, когда сервер с данными временно недоступен. Также проект демонстрирует умение настраивать роутинг между тремя страницами: главной, списком заметок и формой создания. В финале работы проверяется способность собрать проект в продакшен-режиме, чтобы убедиться, что приложение готово к развертыванию.

## Как запустить проект

Для начала работы необходимо убедиться, что на компьютере установлена среда выполнения Node.js. Все дальнейшие действия выполняются в терминале. Сначала нужно открыть папку с проектом и установить все необходимые зависимости. Для этого выполните команду:

```bash
npm install
```

Так как проект состоит из двух частей — клиентской части и сервера с данными, — потребуется открыть два терминала.

**Терминал 1: Сервер с данными**

В первом терминале запускается сервер с данными. В корневой папке проекта, где находится файл базы данных, выполните команду:

```bash
npx json-server --watch db.json --port 3000
```

После запуска сервер начнет отдавать данные по адресу, который нужно будет проверить в браузере: при переходе по адресу `http://127.0.0.1:3000/notes` должен отображаться список заметок в формате JSON. Этот терминал нельзя закрывать, пока вы тестируете приложение.

**Терминал 2: Клиентская часть**

Во втором терминале запускается сама клиентская часть. Выполните команду:

```bash
ng serve
```

После непродолжительной компиляции в терминале появится адрес, по которому доступно приложение (обычно это `http://127.0.0.1:4200`). Открыв этот адрес в браузере, вы увидите главную страницу приложения. С помощью верхнего меню можно перемещаться между страницами, просматривать заметки и добавлять новые. Если вы остановите сервер с данными в первом терминале, то при обновлении страницы со списком заметок приложение должно корректно отобразить сообщение об ошибке, а не зависнуть в бесконечной загрузке.

## Сборка проекта

Когда приложение полностью проверено в режиме разработки, можно выполнить продакшен-сборку. Для этого выполните команду:

```bash
ng build --configuration production
```

После успешного завершения в папке `dist` появится готовая к публикации версия приложения. Запустить ее локально можно с помощью команды:

```bash
npx http-server dist/my-app/browser
```
