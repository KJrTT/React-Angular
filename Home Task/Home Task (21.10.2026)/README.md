# Домашнее задание: localStorage и React Router

Практическая работа по закреплению работы с хранилищем браузера и навигацией в React.

## Часть 7: localStorage
1. **Счётчик с сохранением** — состояние сохраняется при перезагрузке страницы.
2. **Тема с сохранением** — выбор светлой/тёмной темы запоминается.
3. **Черновик заметки** — текст сохраняется автоматически с задержкой (debounce) 500 мс.
4. **Очистка данных** — кнопка сброса с подтверждением очищает сохраненные данные.

Для удобства создан кастомный хук `useLocalStorage`, который автоматически синхронизирует состояние React с `localStorage`.

## Часть 8: React Router
5. **Блог** — маршруты для главной (`/`), списка постов (`/posts`) и отдельного поста (`/posts/:id`).
6. **Хлебные крошки** — навигация внутри детальной страницы поста.
7. **Защищенный маршрут** — переход на страницу админа (`/admin`) перенаправляет на главную, если у пользователя нет прав.
8. **Query-параметры** — фильтрация списка пользователей по городу через URL (`/users?city=Москва`).
