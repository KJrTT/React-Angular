# Todo App with Favorites (Angular)

Учебный проект на Angular, демонстрирующий взаимодействие двух сервисов и реактивное обновление пользовательского интерфейса. 

## Описание задачи
Проект реализует систему «Избранное» для списка задач (Todo). 
Взаимодействие построено между тремя сущностями:
- **TodoService** — управляет списком задач (создание, удаление).
- **FavoritesService** — управляет списком избранных задач (хранит ID в `Set`).
- **UI Компоненты** — отображают список и реагируют на изменения в реальном времени.

## Функционал
- Отображение списка задач.
- Добавление/удаление задачи из избранного по клику на звездочку (`⭐` / `☆`).
- Динамический счетчик избранных задач в реальном времени (компонент `favorites-counter`).
- Автоматическое удаление задачи из избранного при её удалении из общего списка (счетчик корректно уменьшается).

## Стек технологий
- **Angular** (Standalone Components)
- **TypeScript**
- **RxJS** (использование `BehaviorSubject` для реактивности)
- **CSS/SCSS** (базовые стили)
