# Домашнее задание

## Описание проекта
Учебный проект «Каталог студентов», демонстрирующий базовые и продвинутые концепции React (компоненты, пропсы, условный рендеринг, списки).

## Что реализовано в проекте:

**Уровень 1 (Базовый):**
1. **Компонент `Footer`** — футер с динамическим отображением текущего года.
2. **Компонент `Badge`** — переиспользуемый бейдж для отображения курса, принимающий текст и цвет. Используется внутри карточки студента.
3. **Условный рендеринг** — в карточке студента отображается значок «Отличник», если средний балл (GPA) >= 4.5.

**Уровень 2 (Средний):**
4. **Иконки в `StatCard`** — блок статистики теперь принимает пропс `icon` для визуального выделения показателей.
5. **Аватары студентов** — в `StudentCard` добавлена генерация аватара через сервис `ui-avatars.com` на основе имени.
6. **Декомпозиция навыков** — блок с навыками вынесен в отдельный компонент `SkillsList`, принимающий массив строк.

## Стек
- React
- Vite
- JavaScript (JSX)
