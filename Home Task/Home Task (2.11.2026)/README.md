# Упражнения: назначение

Этот раздел предназначен для практической отработки условных конструкций C++ после изучения теоретической части руководства. Упражнения нужны для того, чтобы закрепить синтаксис `if`, `if-else`, `if-else if-else`, тернарного оператора `?:` и `switch`, а также научиться правильно применять логические операторы `&&`, `||`, `!` и операторы сравнения.

Выполнение заданий помогает:

- **Закрепить синтаксис** каждой конструкции на практике, а не только на чтении примеров.
- **Научиться выбирать инструмент** под задачу: когда достаточно `if-else`, когда уместна цепочка `if-else if`, когда удобнее `switch`, а когда — тернарный оператор.
- **Отработать типичные ловушки**: `=` вместо `==`, сравнение `double` с допуском, смешанное сравнение signed/unsigned, забытый `break`, «висячий `else`», точку с запятой после `if`.
- **Понять короткое замыкание** `&&` и `||` и научиться использовать его для безопасных проверок (например, защиты от деления на ноль).
- **Разобраться с приоритетом операторов** и необходимостью скобок в составных условиях.
- **Потренировать приведение типов** в условиях через `static_cast`.
