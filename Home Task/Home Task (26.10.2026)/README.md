# Домашнее задание: Context API и продвинутые хуки

Практическая работа по закреплению глобального состояния и оптимизации в React.

## Часть 9: Context API
1. **Тема через Context** — переключение светлой/тёмной темы с сохранением в `localStorage`.
2. **Авторизация через Context** — глобальное состояние пользователя (`login`, `logout`).
3. **Корзина через Context + useReducer** — добавление и удаление товаров, подсчёт итоговой суммы.

Для удобства и предотвращения ошибок созданы кастомные хуки (`useTheme`, `useAuth`, `useCart`).

## Часть 10: Продвинутые хуки
4. **useDebounce** — кастомный хук для поиска с задержкой. Показывает индикатор «печатает...», пока не сработает таймер.
5. **usePrevious** — кастомный хук, возвращающий предыдущее значение состояния.
6. **Оптимизация списка** — компонент списка, где элементы обёрнуты в `React.memo`, а функция удаления стабилизирована через `useCallback`. Родительский компонент можно перерисовывать, но элементы списка не будут перерисовываться без необходимости (проверяется через `console.log`).
