# Домашнее задание: useEffect и работа с формами

## Описание
Практическая работа по закреплению хуков `useEffect` и `useRef`, а также работы с API и формами в React. Все задания реализованы в виде отдельных компонентов в папке `src/components`.

## Часть 5: Работа с API (useEffect)
1. **CatFact** — загрузка случайного факта о котах с `catfact.ninja`. Обработка состояний загрузки и ошибки. Кнопка «Ещё» делает новый запрос.
2. **Weather** — получение текущей температуры по названию города. Сначала запрос к API геокодинга для получения координат, затем запрос к API погоды.
3. **Pagination** — постраничный вывод постов с `jsonplaceholder`. Кнопки «Назад/Вперёд» меняют номер страницы, запрос повторяется через `useEffect`.
4. **DebouncedSearch** — поиск по постам с задержкой 500 мс. Используется `setTimeout` внутри `useEffect` с функцией очистки (`clearTimeout`), чтобы не спамить сервер при каждом нажатии клавиши.

## Часть 6: Формы и useRef
5. **ReviewForm** — форма отзыва (имя, оценка, текст). Валидация минимальной длины, блокировка кнопки отправки, сброс после успеха.
6. **DependentForm** — выбор страны и города, где правила валидации города меняются в зависимости от выбранной страны.
7. **FocusOnErrorForm** — при ошибке валидации фокус автоматически переводится на первое невалидное поле с помощью `useRef`.
8. **FileInput** — получение имени выбранного файла через `useRef` без хранения самого файла в состоянии.
9. **InactivityTimerForm** — если пользователь не вводит текст 30 секунд, появляется подсказка. Используется `useRef` для таймера и `useEffect` с очисткой.
10. **MultiStepForm** — пошаговая форма (личное, адрес, подтверждение). Кнопки «Назад/Далее», проверка валидности на каждом шаге.

## Стек

- Vite
- Fetch API
