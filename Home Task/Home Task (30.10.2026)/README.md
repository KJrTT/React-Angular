## О проекте

Учебный SPA-проект на React + TypeScript + Vite. Показывает интеграцию стека: задачи грузятся с публичного API jsonplaceholder, избранное сохраняется в localStorage, фильтры работают через query-параметры, удаление — оптимистичное.


## Что должно быть установлено

- Node.js версии 18 или выше (рекомендуется 20)
- npm версии 9 или выше (идёт вместе с Node.js)
- Современный браузер (Chrome, Firefox, Edge, Safari)
- Интернет — данные грузятся с https://jsonplaceholder.typicode.com

Проверить версии:

```
node -v
npm -v
```

## Как запустить

1. Перейти в папку проекта:

```
cd task-tracker
```

2. Установить зависимости:

```
npm install
```

3. Установить библиотеки проекта (если их ещё нет в package.json):

```
npm install react-router-dom react-hook-form zod @hookform/resolvers @tanstack/react-query
```

4. Запустить dev-сервер:

```
npm run dev
```

Открыть в браузере: http://localhost:5173

### Продакшн-сборка

```
npm run build
npm run preview
```

`npm run build` собирает проект в папку dist и заодно проверяет TypeScript. `npm run preview` запускает локальный предпросмотр собранной версии.

## Что есть в проекте

Страницы и функции:

- Главная страница `/` — краткое описание и кнопка перехода к задачам
- Страница задач `/tasks` — список задач с API, форма создания, фильтр «Все / Избранные»
- Страница деталей `/tasks/:id` — полная информация о задаче
- Страница 404 `*` — вне Layout, без шапки

Работа с данными и состоянием:

- Загрузка задач через TanStack Query (кэш, loading, error, refetch)
- Создание задачи через React Hook Form + Zod (валидация в реальном времени)
- Оптимистичное удаление через useMutation: onMutate убирает задачу из кэша сразу, onError возвращает её при ошибке, onSettled синхронизирует
- Избранное в Context API + localStorage через кастомный хук useLocalStorage
- Фильтр избранного хранится в query-параметре `?filter=favorites` — ссылку можно скопировать и открыть в новой вкладке
- Кнопка «Очистить» в шапке, видна только когда избранное не пустое
- Пустые состояния через отдельный компонент EmptyState

Типизация:

- ApiTask — структура ответа API
- TaskFormValues — тип формы, выведенный из Zod-схемы через z.infer
- FavoritesContextValue — контракт контекста
- useLocalStorage<T> — generic-хук с кортежем через as const

## Для чего сделан

Проект собран как финальная работа по курсу. Задача была не выучить новый инструмент, а показать, что все части стека работают вместе осмысленно:

- Типизация контекстов и кастомных хуков через generics
- Zod-схема как единый источник и валидации, и TypeScript-типа
- as const при возврате кортежа из хука
- Оптимистичное обновление кэша TanStack Query с rollback при ошибке
- Состояние фильтра в URL, а не в локальном стейте

## Что проверено

- npm run build проходит без ошибок TypeScript
- Ссылка `?filter=favorites` открывается в новой вкладке и применяет фильтр
- Кнопка «Очистить» появляется только при непустом избранном
- EmptyState принимает title: string — при title={42} TypeScript ругается
- При удалении в режиме Offline задача сначала исчезает, потом возвращается с alert (rollback работает)
- localStorage не ломается при битых данных (try/catch в хуке)
